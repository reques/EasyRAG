05 / MAKE IT YOURS

下一站，
你的知识空间。

准备 Docker 和一个可用的对话模型 API Key，
从一次本地部署开始。

阅读完整部署指南 ↗
你的下一位搭档，
已经准备好了。 ✦
terminal
# 01 获取项目
git clone https://github.com/reques/EasyRAG.git
cd EasyRAG

# 02 创建配置文件
cp .env.template .env

# 03 在 .env 填写模型 API Key 后启动
docker compose up -d
↳ 服务就绪后访问 http://localhost:5173

首次启动需下载镜像与嵌入模型。Windows PowerShell 使用 Copy-Item .env.template .env 创建配置。
