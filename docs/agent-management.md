# 智能体管理

打开 [智能体管理](http://localhost:5173/agents)，或点击侧栏「智能体」。

## 智能体

主智能体和子智能体分区展示，支持按名称、标识、说明搜索。全局预置来自现有运行时：主智能体为智能助手（dynamic）与深度研究（deepagents），子智能体来自 `DEEP_SUBAGENTS_FILE` 或内置 research/coding 配置。它们可查看、使用、复制，不会通过个人操作改写全局配置。

新增个人智能体时配置名称、类型、说明、角色指令、默认模型与工具范围。主智能体选择深度研究模式后可关联可委派的子智能体；子智能体可以继承主模型，也可以选择自己的模型。主智能体和子智能体类型保存后不可互换，可复制后重新创建。

- 「去对话」在新草稿中选择该主智能体；「试用」将子智能体作为独立角色运行。
- 聊天顶部可切换智能体，所选默认模型随之带入；也可以在对话中显式选择其他模型。
- 点击旧的「深度研究」开关会退出显式智能体选择，回到原有自动路由行为。
- 个人配置支持编辑、复制、启用/停用、删除。被主智能体引用的子智能体需要先解除关联才能删除。已停用的关联子智能体不会进入新执行的可委派名册。
- 所有个人读写与模型引用均按当前账号校验。角色指令不会放开知识库、Skill、沙箱或注册表权限。每个执行保留准入时解析的配置；恢复时沿用已保存的角色/子智能体快照，同时重新检查当前归属、启用状态与模型授权。
- 配置修改影响下一次执行；已有对话和已完成结果保留。

## 模型供应商

「模型供应商」页签按现有模型目录的供应商名称分组，复用 `custom_model_configs` 与原有聊天模型选择。每条模型连接独立保存 API 地址、模型 ID、凭据、温度和图片支持设置。

全局环境预置显示配置是否就绪；个人连接可以新增、编辑、删除和进入对话使用。「配置就绪」表示必需配置完整，不等于网络连通性或模型质量已经验收。

编辑已有连接时 API Key 不回显，留空保留原加密密钥，填写新值则替换。需要密钥但尚未保存时必须填写。删除被个人智能体引用的模型会返回明确提示，应先修改智能体默认模型。云端模型继续使用原有 HTTPS/地址校验，本地连接支持本机、局域网与 Docker 服务地址。

Docker 后端访问宿主机 Ollama 时可用 `http://host.docker.internal:11434/v1`。

## 部署与验证

应用增量迁移 `scripts/migrations/20261101_agent_configs.sql` 后，重建并重新创建前后端。`init_db` 也已注册新表；生产部署应显式应用迁移。现有 Langfuse 网络仍通过 `scripts/local_langfuse.py app ...` 包装保留。

```powershell
.\.venv\Scripts\python.exe scripts/verify_agent_management_live.py --live --model-id deepseek-v4-flash
```

该脚本会创建并保留合成账号、个人模型连接与三个智能体，实际调用所选已配置模型，核验个人角色指令、主→子委派、calculator、独立试用、停用拒绝、模型编辑与密钥保留。默认工作目录 `tmp/agent-management-live/`；`private.json` 含合成账号凭据，仅存于忽略目录；`report.json` 为不含密钥的验收结果。换用新的 `--work-dir` 可进行独立验收。
