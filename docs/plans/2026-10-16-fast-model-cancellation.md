# 快速中断模型请求

目标：点击停止后，中断正在等待响应的模型 HTTP 请求，保留现有用户隔离、持久事件及断线重连语义。

复现：真实 LangGraph + OpenAI 兼容本地 TCP 接口；上游不返回响应头时，旧实现超过 1.5 秒仍未取消。此前真实 DeepSeek 验收的取消终态延迟为 36.67 秒。

原因：同步模型读取阻塞在网络 I/O，图输出循环中的取消检查必须等待下一段模型输出，不能关闭正在等待的连接。

实现：使用 HTTPX 公共 Transport 接口，把同步模型 I/O 桥接到一个进程内专用异步循环；同步和异步读取均按任务信号取消 await，并等待该次连接清理。客户端连接池复用，不关闭其他会话的请求。`AgentRunCancelled` 继续作为独立控制流穿透 SDK 重试及业务兜底。信号轮询间隔为 20ms，不代表用户端确认耗时承诺。

验证：先验证上游无响应头、正文流停顿、推理流停顿、取消不重试，以及共享客户端的并发隔离；再运行已有权限、断线、取消竞态和模型适配回归。根目录 tests 继续仅在本地保留。使用真实 DeepSeek 比较请求取消到持久 cancelled 终态的延迟；通过后只提交本批文件，同步 main/home 并重建、重启服务。

边界：HTTP 连接关闭无法保证供应商一定停止远端计费或撤销已经执行的工具写操作。浏览器断开不会设置任务取消信号。

提交前验证：187 项相关 Python 回归通过，包含 12 项真实 TCP/SDK 连接测试。真实 DeepSeek + LangGraph 在取消信号发出后约 0.0164 秒退出模型调用；完整浏览器确认延迟另在部署后核验。此数值为本机单次测量，不作为供应商响应时间或计费承诺。

真实环境兼容性：模型请求保留旧 LangChain 传输的 `Accept-Encoding: gzip, deflate`。HTTPX 按本机可选依赖自动加入 zstd 时，当前兼容网关可能返回缺少编码标记的压缩 SSE；约束协商格式可避免该回归，同时保留标准压缩响应解码。
