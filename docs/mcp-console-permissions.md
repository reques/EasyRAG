# MCP 页面权限

MCP 是应用共享的工具服务配置，连接地址、Headers、环境变量和令牌属于管理员配置。

| 功能 | 普通账号 / viewer | 管理员 / 超级用户 |
| --- | --- | --- |
| 查看脱敏服务状态、计数、已放行工具 | 可以 | 可以 |
| 查看完整连接配置和原始错误 | 不可以 | 可以 |
| 添加、编辑、删除、连接、断开、同步服务 | 不可以 | 可以 |
| 浏览 MCP 广场及安装服务 | 不可以 | 可以 |
| 在对话中使用已放行的共享工具 | 沿用已有 Skill / 工具 / 沙箱权限 | 沿用已有 Skill / 工具 / 沙箱权限 |

页面先请求登录后可用的 `/api/v1/mcp/overview`，根据后端返回的 `can_manage` 决定展示。普通账号显示只读说明，不再请求 `/mcp/servers` 等管理员接口。服务概览不返回连接 URL、Headers、令牌、环境变量、命令、目录、配置描述或原始错误。

管理员继续使用原管理接口。即使修改浏览器本地角色或强行调用隐藏按钮，后端仍执行管理员校验；配置读权限在概览查询后被撤销时，页面回退到脱敏视图。修复不提升现有用户角色。

工具白名单保持一致语义：省略或 `None` 使用原默认 `['*']`；显式 `[]` 禁止全部工具，刷新时撤销此前注册的工具。广场安装不会再把空白名单转换为全量允许。
